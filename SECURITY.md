# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in JU-Socialz, please do **not** open a public issue.

Instead, send a private report to the repository maintainers via GitHub's [security advisory](https://github.com/Madhavk005/JU-Socialz/security/advisories/new) feature.

Please include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

You should receive a response within 5 business days. If the issue is confirmed, we will work on a fix and coordinate disclosure.

## Scope

- The Next.js application at `ju-socialz.com` (or custom domain)
- The Sanity Studio at `ju-socialz-dashboard.sanity.studio`
- API routes under `/api/*`

## Out of Scope

- Social engineering attacks
- DDoS attacks
- Attacks requiring physical access to a user's device
